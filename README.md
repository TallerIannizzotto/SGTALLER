# SGTaller v1.7

PWA de gestión de siniestros. React + Vite + Google Drive + Gemini AI.

## Variables de entorno en Vercel
- VITE_GOOGLE_CLIENT_ID
- VITE_GOOGLE_CLIENT_SECRET  
- GEMINI_API_KEY

## Correr localmente
```bash
npm install
npm run dev
```

## Deploy
```bash
git add .
git commit -m "update"
git push origin main
```
Vercel redeploya automáticamente.
